# Автоматическое форматирование перед коммитом

Установите зависимости разработчика один раз из корня репозитория:

```bash
python -m pip install -r backend/requirements-dev.txt
python -m pre_commit install
```

Теперь при обычном `git commit` запускаются Ruff lint с `--fix` и
Ruff format для изменённых Python-файлов. Если инструменты исправили код,
коммит остановится: проверьте изменения, повторно добавьте файлы
(`git add ...`) и повторите `git commit`. Это предотвращает коммит
непроверенных автоматических правок.

Один раз запустить хуки на всех файлах:

```bash
python -m pre_commit run --all-files
```

Хуки локальные: они **не срабатывают** при изменении файлов через GitHub API,
веб-интерфейс или напрямую через подключённые инструменты. Независимая проверка
в GitHub Actions (`ruff check` и `ruff format --check`) остаётся обязательной.

`pre-commit` устанавливается в виртуальное окружение Python, но hook-процессы
Ruff управляются самим pre-commit и скачиваются при первом запуске.
